# Vai de Carro

`vaidecarro.com` is a product concept for a ride-hailing platform focused exclusively on car trips.

Instead of cloning Uber screen by screen, this project explores the core product logic behind a Brazilian urban mobility service:

- route selection between real points in Manaus;
- fare estimation based on distance, duration, ride class, and demand;
- nearby-driver matching;
- a passenger flow and a driver dashboard in the same experience;
- a roadmap that makes the next technical layers explicit.

## Demo highlights

- Passenger booking panel with origin, destination, and category selection
- Dynamic fare calculation
- Mock live map with nearby drivers and route visualization
- Driver panel with demand simulation
- Responsive landing page and polished product positioning

## Tech stack

- React 19
- Vite 8
- CSS

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Product roadmap

1. Authentication for passengers and drivers
2. Real maps and geolocation integration
3. Payments, wallet, and promo codes
4. Real-time dispatch backend
5. Admin dashboard and analytics

## Why this project matters

This repository was designed as a portfolio-grade MVP: it demonstrates frontend craft, product thinking, state management, pricing logic, and the ability to turn an idea into a coherent first release.
